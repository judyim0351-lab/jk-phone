# 아이폰 16 시뮬레이터

브라우저에서 진짜 아이폰처럼 만질 수 있는 iOS 18 스타일 프로토타입이에요.

## 기능
- 잠금화면 → 위로 쓸어올리기 → 암호 입력 (암호: 1230)
- 홈 화면 2페이지 (옆으로 넘기기), 독
- 메시지 · 카카오톡: 메시지를 보내면 정해둔 답장이 와요
- 전화: 연락처·최근 기록·키패드, 통화하면 대사가 자막처럼 떠요
- 홈 화면 맨 위에서 아래로 쓸어내리면 잠금화면(알림 센터)

## 수정하는 법
`index.html` 안의 `CONFIG` 부분만 고치면 돼요.
- `contacts` : 연락처
- `sms`, `kakao` : 처음 대화 내용
- `replies` : 자동 답장 규칙
- `calls` : 통화 대사
- `passcode` : 잠금 암호

## 배포
파일 하나(`index.html`)로 동작해요. 이미지와 아이콘이 모두 파일 안에 들어 있어요.
- **Vercel:** 이 저장소를 Import 하면 바로 배포돼요 (빌드 설정 필요 없음).
- **GitHub Pages:** Settings → Pages → Branch `main` / root 선택.
